# QTrader — 국내·미국 주식 AI 퀀트 자동매매

토스증권 Open API(또는 한국투자증권 Open API)로 국내(KOSPI/KOSDAQ)와 미국 주식을
전략이나 AI 투자 회의 결과에 따라 자동으로 매매하는 PC 설치형 프로그램입니다. 화면은 브라우저로 열리는
로컬 대시보드(http://127.0.0.1:8765)이고, 외부 인터넷에는 열리지 않습니다.

> 이 프로그램은 투자 권유가 아닙니다. 백테스트와 AI 분석은 추정이며 미래 수익을
> 보장하지 않습니다. 모든 매매 판단과 손익은 사용자 본인의 책임입니다.

개발 안내는 [CLAUDE.md](CLAUDE.md), 남은 작업은 [docs/NEXT.md](docs/NEXT.md), 처음 설계는 [docs/architecture-v0.md](docs/architecture-v0.md)에 있습니다.

## 2차 고도화 (2026-10-27)

- **종목 화면**: 위쪽 검색창(코스피·코스닥·나스닥·뉴욕·아멕스 전 종목) → 실시간 시세(3초), 캔들/라인, 1·5·15·60분·일·주·월봉,
  이동평균 5·20·60·120, 거래량, 호가(매수/매도 잔량 비율), 체결, 재무제표(국내 DART·미국 SEC, 매출·영업이익·순이익 차트와
  영업이익률·ROE·부채비율·PER·PBR), 투자자별 매매, 종목 뉴스, AI 회의 기록
- **시장 탭**: 시간대에 맞춰 국내(코스피·코스닥) / 미국(S&P500·나스닥100·다우, ETF 기준) 자동 전환, 종목 아이콘, 순위에서 바로 종목 화면
- **뉴스 탭**: 인베스팅닷컴 주식시장 RSS 등 (제목·링크만, 본문은 원문 사이트)
- **뇌동매매 방지 체크리스트**: 퀀트 연구 20편(모멘텀, 시계열 모멘텀, 200일선, 변동성, 켈리, 과잉매매 등)을 근거로 한 13개 규칙.
  하나라도 어기면 AI 가 매수라고 해도 사지 않음. 포지션 크기는 절반 켈리와 변동성 목표 중 작은 값
- **실행 계획**: 사는 가격대, 손절가·익절가(금액), 추천 수량, 최대 손실·예상 이익. 산 종목은 장중 2분마다 손절·익절 자동 점검
- **주문 근거**: 승인 대기·주문 내역마다 AI 의견, 확신도, 체크리스트 결과, 손절·익절가를 문장으로 저장
- **빠른 회의(기본)**: Claude 7회(정밀 14회). 모든 참석자가 같은 지침·자료를 받아 프롬프트 캐시가 맞고, 1라운드 토론과 리스크 위원회는 동시 진행.
  회의마다 호출 수와 예상 비용(원)을 표시
- **AI 사무실**: 2등신 픽셀 캐릭터(역할별 머리 모양·안경·넥타이·헤드셋), 더 빠른 움직임, 회의가 끝나면 '사는 가격·손절·익절·수량' 카드
- 백테스트 탭 제거

## 1차 고도화 (2026-10-27)

- **참석자 14명**: 분석가 5명(기술·재무/밸류·실적/가이던스·뉴스·수급/심리) → **검증관**(팩트체크 + 투자 전 필수 질문 5가지 조사 +
  밸류에이션·분야별 점수) → 강세/약세 토론 → 팀장(투자 논문·숏 논거와 반박·시나리오) → 트레이더 → 리스크 3명 → 대표
- **투자자 프로필**: 설정에 쓴 투자 목표·위험 성향을 모든 참석자가 기준으로 삼습니다 (가이드 STEP 0)
- **근거 규칙**: 출처 표기, 확실/해석 구분, 출처 불명 표현 금지, 원화 환산, 영문 용어 병기 (클로드 가이드 프로젝트 지침)
- **빠른/깊은 모델 분리**: 분석가·토론자는 `claude-sonnet-5-5`, 검증관·팀장·대표는 `claude-opus-5-5` (비용 절약, 설정에서 변경)
- **분석 결과 대시보드**: 최종 의견·확신도·진입/손절/익절·손익비, 캔들 차트(이평·지지/저항·시나리오 선), 분야별 점수 레이더,
  시나리오와 확률 가중 기대값, 밸류에이션(현재/5년 평균/경쟁사), 투자 논문, 숏 논거와 반박, Trust/Worry/Watch, 팩트체크 표,
  추가 질문 Q&A, 토론 기록
- **AI 사무실 확대**: 6개 방, 일하는 참석자가 자료실·동료 책상을 오가고, 보고서가 끝나면 서류가 다음 담당자에게 날아갑니다. 단계 표시줄과 진행 시간·토큰 표시
- **승인 대기 주문**: AI 전략 주문은 기본으로 `내 계좌 → 승인 대기 주문`에서 승인해야 나갑니다. 승인할 때 리스크 한도를 다시 확인합니다
- **AI 판단 기록**: 모든 회의 결정과 그 뒤 실제 가격을 비교해 방향 적중률·평균 수익을 그대로 보여줍니다
- **계산기 탭**: 목표 자산 복리 계산기, 포지션 크기 계산기, 미국 주식 양도소득세 계산기(250만원 공제, 22%)

> 승률 100% 는 어떤 방법으로도 보장할 수 없습니다. QTrader 는 근거를 검증하고, 손실을 제한하고, 결과를 숨김없이 기록하는 데 집중합니다.

## AI 투자 회의 (TradingAgents 구조)

[TradingAgents](https://github.com/TauricResearch/TradingAgents)(Apache-2.0)의 다중 에이전트 흐름을
따르고, 프롬프트·데이터 연결은 국내 시장용으로 새로 썼습니다. 모델은 Claude(기본 `claude-opus-5-5`).

```
분석팀(동시 진행)        차트봇(기술) · 밸류(재무, 웹) · 헤드라인(뉴스, 웹) · 수급왕(수급·여론, 웹)
  → 토론실               불리(강세) ↔ 베어리(약세) 토론 → 팀장(리서치 팀장) 투자 계획
  → 트레이딩 데스크      트레이더 실행안 (방향·비중·손절·익절)
  → 리스크 위원회        돌격(공격) · 저울(중립) · 방패(보수) 토론
  → 대표실               대표(포트폴리오 매니저) 최종 결정: Buy / Overweight / Hold / Underweight / Sell
```

- 회의 자료는 토스증권 일봉으로 계산한 수익률·이동평균·RSI·볼린저·ATR·52주 위치, 국내 종목의 투자자별 순매수입니다.
- 시장 전략을 **AI 투자 회의**로 고르면 실행 시각 40분 전부터 종목마다 회의를 열고, 최종 등급으로 목표 비중을 정합니다
  (Buy 1.0 · Overweight 0.7 · Underweight 0.3 · Sell 0 × 종목당 1/N). Hold·확신 부족·회의 없음은 **보유 유지**입니다.
  그 뒤 같은 리스크 관리(비중 상한, 킬 스위치, 주문 한도)를 통과한 주문만 나갑니다.
- 회의 1번에 Claude 호출이 약 12번 일어납니다. 하루 회의 종목 수 상한(기본 8)으로 비용을 묶습니다.
- 거절 응답에는 서버 쪽 대체 모델(`fallbacks: "default"`)이 이어 받도록 설정돼 있습니다.

### 비서

AI 사무실 아래 대화창. 시장 현황·순위·시세·차트 요약·내 계좌·주문 내역·최근 회의 결론을 도구로 직접 확인해서 답하고,
"OO 회의 열어줘"라고 하면 회의를 엽니다. **비서는 주문을 내지 않습니다.**

## 토스증권 연결

1. 토스증권 Open API를 신청해 Client ID / Secret 을 받습니다.
2. 토스증권 WTS(PC 웹) → 설정 → Open API → **허용 IP 관리**에 이 PC의 공인 IP를 등록합니다. 등록하지 않으면 403.
3. 대시보드 설정 → API 키 → "토스증권"으로 저장. 시세 출처가 자동이면 바로 실제 시세로 바뀝니다.
4. 토스증권은 모의투자가 없습니다. **가상매매 모드(실제 시세 + 내 PC 안 체결)**로 충분히 돌려 본 뒤 실전을 검토하세요.
5. 실전: 모드 "토스증권 실전" + 실전 주문 허용 체크 + `실전주문` 입력. 주문마다 멱등성 키(clientOrderId)를 붙여 같은 주문이 두 번 나가지 않습니다.
   미국 주문은 기본 LOC(장 마감 지정가)입니다. 휴장일은 토스증권 장 운영 정보로 거릅니다.

엔드포인트와 필드는 공식 명세 `openapi.tossinvest.com/openapi-docs/latest/openapi.json` (v1.2.24) 기준입니다.

## Claude API 키

설정 → API 키 → "Claude API 키"로 저장하거나 `ANTHROPIC_API_KEY` 환경변수를 씁니다.

## 기능

- **전략**: 추세추종(이동평균 + 변동성 조절), 모멘텀 순위(상위 K종목 정기 교체), 평균회귀(RSI·볼린저), AI 투자 회의
- **백테스트**: 수수료·거래세·슬리피지 반영, CAGR·MDD·샤프·소르티노·회전율, 동일비중 보유와 비교 차트
- **운용 모드**: 가상매매(내 PC 안에서만 체결) · 토스증권 실전 · KIS 모의투자 · KIS 실전
- **자동 실행**: 시장별 실행 시각(국내 15:10 KST, 미국 15:45 뉴욕 시간)에 하루 한 번. 서머타임 자동 처리
- **리스크 관리**: 종목당 최대 비중, 총 투자 비중 상한, 1회 주문 한도, 일일 손실 한도 → 킬 스위치, 같은 날 중복 주문 방지
- **보안**: API 키는 윈도우 자격 증명 관리자에 저장, 대시보드는 127.0.0.1 전용 + 실행마다 바뀌는 토큰

## 설치 (개발 버전)

Python 3.11 이상이 필요합니다.

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -e .
```

## 빠른 시작

1. **체험용 데이터 만들기** (키 없이 화면과 전략을 확인할 때. 실제 시세가 아닙니다)
   ```bash
   .venv\Scripts\qtrader demo-data
   ```
2. **대시보드 열기** — `QTrader 실행.cmd` 를 더블클릭하거나:
   ```bash
   .venv\Scripts\qtrader serve
   ```
3. **백테스트** 탭에서 전략과 기간을 고르고 실행해 봅니다.
4. **대시보드** 탭의 "지금 계산만"으로 오늘 어떤 주문이 나갈지 미리 봅니다.

## 실제 시세와 모의투자 연결

1. [KIS Developers](https://apiportal.koreainvestment.com/)에서 API를 신청하고 **모의투자** 앱키/시크릿을 받습니다.
2. 대시보드 **설정 → 한국투자증권 API 키**에 "모의투자"로 저장하고, 계좌번호(`12345678-01`)를 넣습니다.
3. 가상매매 모드 그대로 두면 **시세만 KIS에서** 받아옵니다. 모드를 "KIS 모의투자"로 바꾸면 모의계좌로 주문합니다.
4. 모의투자로 최소 몇 주 이상 돌려 보고 주문 내역·로그를 확인한 뒤에 실전을 검토하세요.

### 실전으로 바꿀 때

실전 주문은 세 단계를 모두 거쳐야 나갑니다.
1. 설정에서 모드 "KIS 실전" 선택
2. "실전 주문을 허용합니다" 체크 후 `실전주문` 입력
3. 자동매매 시작이나 즉시 실행 때 다시 `실전주문` 입력

처음에는 **운용 한도(budget)** 와 **1회 주문 한도**를 작게 잡으세요.

## 명령어

| 명령 | 하는 일 |
| --- | --- |
| `qtrader serve` | 대시보드 + 자동매매 스케줄러 |
| `qtrader backtest --market KR --strategy momentum` | 백테스트 결과 JSON 출력 |
| `qtrader run --market KR --dry-run` | 지금 한 번 계산만 (주문 안 함) |
| `qtrader run --market US` | 지금 한 번 실행 |
| `qtrader set-keys --env demo --account 12345678-01` | 키 저장 (입력은 화면에 안 보임) |
| `qtrader kill on` / `off` | 킬 스위치 |
| `qtrader demo-data` | 체험용 합성 시세 CSV 생성 |

데이터 폴더: `%APPDATA%\QTrader` (설정 `config.json`, DB `qtrader.db`, CSV `data\`).
`QTRADER_HOME` 환경변수로 바꿀 수 있습니다.

## 종목 표기

- 국내: 6자리 코드 `005930`
- 미국: 나스닥은 `AAPL`, 그 외 `NYSE:KO`, `AMEX:SPY`

## 동작 방식

```
일봉(KIS 또는 CSV) → 전략: 종목별 목표 비중 → 리스크: 비중 상한·킬 스위치 → 현재 보유와의 차이만큼 주문(매도 먼저) → 기록
```

백테스트와 실매매가 **같은 전략 함수**를 씁니다. t일 종가까지의 정보로 정한 비중을
t일 장 마감 직전에 체결한다고 가정하며, 실매매도 장 마감 직전에 돕니다.

## 토스 서버 보호 (OCO · OTO)

- 손절·익절이 정해진 보유 종목은 토스 서버에 **OCO 조건주문**(익절가 위·손절가 아래 둘 중 먼저 닿는 쪽 매도)이 자동으로 걸립니다.
  PC나 QTrader 가 꺼져 있어도 토스가 팝니다. 국내는 **KRX 정규장에서만** 발동하고, 넥스트레이드 시간외는 QTrader 의 2분 감시가 맡습니다. 미국은 모든 시간대에 발동합니다.
- 체결되면 바로, 그 뒤엔 2분마다 '있어야 할 보호'와 '걸린 보호'를 맞춥니다 (수량이 바뀌면 다시 걸고, 계획이 끝나면 취소).
- QTrader 가 직접 팔 때(기간 만료·AI 재점검·리밸런싱·직접 매도)는 먼저 토스 보호를 풀고 팝니다.
- 조건 구매에서 '사지면 바로 손절도 걸기'를 켜면 **OTO**(사면 이어서 손절)로 겁니다.
- 토스 앱에서 직접 건 조건주문도 내 계좌 → 알림 탭 목록에 함께 보입니다 (토스 앱에서 관리).
- 끄기: `config.yaml` 의 `toss.server_guard: false`

## 알려진 한계 (다음 단계)

- **실제 키로 아직 끝까지 확인하지 못한 기능**: 토스 OCO/OTO 걸기·수정·취소, 주문 정정, 외국인·기관 동향, 대차거래, 산업 ETF·분류, 실시간 스트림, 큐비 대화.
  명세(v1.2.24)대로 만들고 가짜 서버로 시험했습니다. 처음에는 **가상매매 → 아주 적은 금액 실전** 순서로 확인하세요
- 토스가 OCO 로 판 경우 체결 가격은 토스 앱 주문내역에서 확인해야 합니다 (QTrader 는 '팔렸다'는 알림과 계획 종료만 기록)
- 휴장일: 토스증권 시세를 쓰면 장 운영 정보로 거릅니다. KIS·CSV 만 쓰면 주말만 거르고 공휴일 주문은 증권사가 거부합니다
- AI 회의 전략은 과거 뉴스를 재현할 수 없어 백테스트하지 않습니다. 가상매매로 먼저 검증하세요
- 미국 지수(S&P500·나스닥·다우)는 토스에 없어 Yahoo Finance 공개 시세를 씁니다 (비공식, 막히면 ETF 로 대신)
- 토스 API 에 실시간 웹소켓이 없어 화면 시세는 2초마다 다시 받아 옵니다
- 자동매매는 프로그램이 켜져 있는 동안만 돕니다 (꺼져 있어도 토스 서버 보호는 동작). PC 절전 모드를 끄세요
- 수익을 보장하지 않습니다. 손실을 작게 끊는 규칙으로 돕는 도구입니다

## 다른 사람에게 배포하기 전에

- 각 사용자가 **자기 키로 자기 PC에서** 돌리는 구조입니다. 개발자가 남의 계좌나 키를 맡지 않습니다.
- 그래도 **매매 신호·종목 추천을 유료로 제공**하면 유사투자자문업 신고 대상일 수 있고,
  남의 계좌를 대신 운용하면 투자일임업 등록이 필요합니다. 출시 전에 금융 전문 변호사에게 확인하세요.
- 사용자에게 위험 고지와 이용약관 동의를 받으세요.
