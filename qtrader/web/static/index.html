로그

    AI 투자 회의 전략은 과거 시점의 뉴스를 재현할 수 없어 백테스트하지 않습니다.

    자산 곡선 파랑: 전략 · 회색: 동일비중 보유

    과거 성과는 미래 수익을 보장하지 않습니다. 비용(수수료·세금·슬리피지)을 반영한 추정치입니다.

    목표 자산 복리 계산기 은퇴 목표까지 매달 얼마를 넣어야 하나

    포지션 크기 계산기 한 번 틀렸을 때 잃을 금액을 먼저 정한다

    AI 회의 결과의 손절가를 넣으면, 틀려도 계좌의 몇 %만 잃는 수량이 나옵니다.

    미국 주식 양도소득세 계산기 한국 거주자 · 연간 손익 통산 · 기본공제 250만원 · 세율 22%(지방세 포함)

    종목수량매수가($)매수일 환율매도가($)매도일 환율수수료(원)손익(원)

    취득가액·양도가액은 각각 결제일 기준환율로 원화 환산합니다. 같은 해 해외주식 손익끼리 통산됩니다. 신고는 다음 해 5월. 참고용이며 정확한 신고는 세무 전문가와 확인하세요.

    운용 모드

    API 키 이 PC의 윈도우 자격 증명 관리자에만 저장됩니다

    토스증권은 WTS 설정 → Open API → 허용 IP 에 이 PC의 공인 IP를 등록해야 주문이 됩니다. 토스증권에는 모의투자가 없으니 연습은 가상매매 모드로 하세요.

    AI 투자 회의

    회의 1번에 Claude 호출이 14번쯤 일어납니다. 종목 수와 라운드가 늘면 비용이 늘어납니다.

    리스크 관리

    이 프로그램은 투자 권유가 아니며, 모든 매매 판단과 손익은 사용자 본인의 책임입니다. AI 회의 구조는 TradingAgents(Apache-2.0)를 참고했습니다.
